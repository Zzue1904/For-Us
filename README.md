# Para nosotros ♡

Una página web romántica creada para guardar y compartir pequeños recuerdos, enlaces y momentos especiales.

## Vista previa

La página tiene una pantalla de bienvenida y, al pulsar el botón, muestra tres tarjetas con enlaces especiales, fotos y corazones animados.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
